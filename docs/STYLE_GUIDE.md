# Runehold TD Style Guide

Runehold TD should feel like a fantasy RTS custom-map tower defense: readable, compact, warm, tactical, and a little ornate. The goal is genre familiarity, not imitation of any specific game.

## IP Boundary

Use broad fantasy RTS usability cues only. Do not copy Warcraft names, factions, icons, models, sounds, maps, units, buildings, spell names, or lore.

## Visual Direction

* **Board**: grass terrain tiles, warm dirt lanes, clear IN/OUT gates.
* **Build plots**: circular rune foundations that are visibly separate from the path.
* **Panels**: compact wood/stone/parchment command UI with high contrast text.
* **Typography**: fantasy display face for titles and headings, readable sans-serif for controls.
* **Effects**: small glows, range rings, hit particles, and floating text that do not hide creeps.
* **Palette**: forest greens, warm dirt browns, parchment gold, mana blue, danger red.

## UI Copy Rules

* Use "War Paths" for levels.
* Use "Build Towers" for tower selection.
* Use "Creep Ledger" for enemy listing.
* Use "Gold" as the visible currency label while keeping `C/S/B` denomination formatting.
* Use "Salvage" instead of "Demolish" for sell/refund.
* Keep text compact and functional.
